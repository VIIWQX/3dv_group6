# 手绘技术解释风

用户指定手绘风格，依据codex-ppt内置同名风格，保持统一视觉语言。

- 16:9，近白纸面 #FCFBF7，禁止泛黄纸张与整页边框。
- 石墨灰 #2F3437 的细而轻微不规则线条，少量铅笔排线。
- 浅蓝 #BFD7F1、鼠尾草绿 #CFE2D1；浅桃 #F4C7B8 仅用于关键误差/提醒。
- 中文标题带克制的手写感，正文标签清晰、稀疏；长解释放演讲备注。
- 流程、结构、证据、比较和总结页采用不同构图，不重复三卡片模板。
- 实验原图与图表作为严格输入嵌入；保留数值、坐标、标签与图像缺陷，不手绘替代真实结果。
- 无水印、无无关Logo、无页码；留足安全边距。
- 图片式PPT：整页视觉由内置图片生成工具创建，文字/图表不作为独立可编辑对象。
